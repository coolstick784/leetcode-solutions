# LeetCode Solutions

This repository is automatically populated from the accepted solutions on the
LeetCode account `coolsahil717`.

The sync runs daily and can also be started manually from the **Actions** tab.

## Required repository secrets

Add these secrets under **Settings → Secrets and variables → Actions**:

- `LEETCODE_CSRF_TOKEN`
- `LEETCODE_SESSION`

These are the values of the `csrftoken` and `LEETCODE_SESSION` cookies from a
logged-in LeetCode browser session. Do not commit them to this repository.
